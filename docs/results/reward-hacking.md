# Reward hacking: episodes and harness

Reward hacking episodes and harness: every finding, newest first. Tags and pointer conventions are explained at the top of [RESULTS.md](../../RESULTS.md), which also carries this thread's summary.

- `[lead 10-05]` A frozen linear hardcoding probe read over all completion tokens and subtracted from the GRPO reward (coefficient 10, selection only, no gradient through the probe, KL 0) turned a released Obfuscation Atlas hardcoder (Gemma-3-12B, MBPP) honest within 8 steps: hacks 95% -> 19%, all-tests passes 0% -> 61%, completions 70 -> 213 tokens, while the matched no-penalty arm sharpened its hacking to 98%. The honesty partly carried to a held-out graded setting (AISI CodeContests special-casing 33/40 -> 13/40; control 36/40; base 0/40). No evasion in 8 steps. Brevity is a partial confound: a placebo arm (random direction with the probe's per-layer norms and recalibrated bias) lengthened completions just as much (59 -> 202 tokens) but cut hacking only to 58% with 25% honest passes, so at matched length the real probe removes more hacking than a length-correlated penalty does (one seed per arm, 64 samples per step). Re-scoring all 1,536 completions with one frozen reader confirms the split: probe score falls steeply with completion length (Spearman -0.84), yet at matched length hacks score 0.16-0.21 above honest code, and adding the probe score to length raises item-grouped hack-vs-honest AUC from 0.71 to 0.92. The frozen reader matches the logged training metric within 0.024 at every step, so the score moved because the text changed, not through hidden-state evasion.
