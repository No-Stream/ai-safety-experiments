- `[est 09-02]` The decoupled-ladder pass replicates a published counterpart-identity x decision-coupling 2x2 (Za, Panos, Cuhel, Albanie; ICLR 2026 AIWILD workshop: coupling +76pp, identity +4pp, "17x") on this repo's banked one-shot matrix games (twin-pd and public-goods, 48 prompt rows x 8 draws per cell, both print orders, the public counterpart clauses plus a mechanism-asserted different-system-coupled corner) across nine hosted models (eight on the hosted batch tier, GPT-5.6 Luna and Claude Sonnet 5 live; ~46k records), then walks a seven-rung counterpart-identity ladder inside the decoupled condition.
